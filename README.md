# لعبة لودو (Flutter)

لعبة لودو بسيطة مبنية بـ Flutter، تدعم:
- اللعب مع أصدقائك على نفس الجهاز (تمرير الجوال - Pass & Play)
- اللعب ضد الكمبيوتر (ذكاء اصطناعي بسيط)
- من 2 إلى 4 لاعبين (أي مزيج بين بشر وكمبيوتر)

## طريقة التشغيل في Android Studio

1. فك ضغط الملف واحصل على مجلد `ludo_game`.
2. افتح Android Studio → File → Open → اختر مجلد `ludo_game`.
3. تأكد إن عندك Flutter SDK مثبت ومربوط بـ Android Studio (Settings → Languages & Frameworks → Flutter).
4. يحتوي المستودع بالفعل على إعدادات منصة Android. افتح Terminal داخل Android Studio ونفذ:
   ```
   flutter pub get
   ```
   لا تنفذ `flutter create .` على نسخة المشروع الحالية؛ فهذا الأمر غير مطلوب وقد يعيد توليد ملفات المنصة.
5. شغّل المحاكي (Emulator) أو وصّل جوالك بكيبل مع تفعيل USB Debugging.
6. اضغط زر Run (▶) أو نفذ:
   ```
   flutter run
   ```

## هيكلة المشروع

```
lib/
  main.dart          نقطة تشغيل التطبيق
  menu_screen.dart    شاشة اختيار اللاعبين (بشري/كمبيوتر/فارغ) لكل لون
  game_screen.dart    شاشة اللعب: النرد، الأدوار، منطق الذكاء الاصطناعي
  ludo_board.dart      رسم اللوحة والمهرات (CustomPainter)
  ludo_logic.dart      قواعد الحركة، الأكل، اختيار حركة الكمبيوتر
  ludo_models.dart     نماذج اللاعب والمهرة
  ludo_data.dart       إحداثيات اللوحة، نقاط الأمان، أعمدة البيوت
```

## قواعد اللعبة المطبّقة
- لكل لاعب 4 مهرات، ولا تخرج المهرة من القاعدة إلا برمية 6.
- رمية 6 تمنح اللاعب رمية إضافية، حتى إذا لم تكن لديه نقلة قانونية بهذه الرمية.
- أكل مهرة خصم في خانة غير آمنة يمنح اللاعب رمية إضافية، حتى لو لم تكن الرمية 6.
- إذا رمى اللاعب الرقم 6 ثلاث مرات متتالية في دوره، تُلغى الرمية الثالثة وينتقل الدور إلى اللاعب التالي.
- يتكوّن الحاجز من مهرتين أو أكثر من اللون نفسه في الخانة المشتركة؛ لا يستطيع الخصم المرور فوق الحاجز أو الوقوف عليه.
- يستطيع اللاعب المرور فوق حاجزه الخاص.
- الخانات الآمنة (المميزة بالنجمة) تمنع أكل المهرات؛ يمكن لمهرات ألوان مختلفة أن تجتمع فيها.
- يجب الوصول إلى خانة البيت بالعدد الدقيق؛ لا يسمح بتجاوزها.
- يفوز أول لاعب يوصل مهراته الأربع إلى البيت.

## تطوير مستقبلي مقترح
- إضافة أصوات ورسوم متحركة للنرد وحركة المهرات.
- دعم اللعب أونلاين بين جوالين مختلفين (يحتاج سيرفر/Firebase).
- إضافة مستويات صعوبة مختلفة للكمبيوتر.
